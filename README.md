# bball-tunnel

Public pointer page for the fairline NBA win-probability app (model vs. Kalshi prices).
The app itself runs on a laptop behind a Cloudflare quick tunnel, read-only; this repo's
GitHub Pages site (https://psycho789.github.io/bball-tunnel/) links to the current tunnel URL,
which changes whenever the tunnel restarts. Published by `deploy/tunnel/share.sh` in the app repo.
